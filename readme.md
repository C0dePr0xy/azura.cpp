# Simple Tasks

A simple program that allows the user to organize and manage their daily tasks in their terminal.

## Author

Eric Guerra

## Version

0.1

## Creation Date

February 12, 2025

## Description

Simple Tasks is a terminal-based application that helps users manage their daily tasks. It includes features such as user login, registration, and task management. I am in the process of completely remaking Simple Tasks!

## Features

- User login and registration
- Task management
- Clear terminal screen based on the operating system (macOS, Linux, and Windows are currently supported)

## Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/yourusername/simple-tasks.git
    ```
2. Navigate to the project directory:
    ```sh
    cd simple-tasks
    ```
3. Compile the program:
    ```sh
    g++ -o simple-tasks src/simple-tasks.cpp
    ```

## Usage

Run the compiled program:
```sh
./simple-tasks
```
